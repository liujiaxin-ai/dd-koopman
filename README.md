# DD-Koopman: Compact Spectral Transfer for Multi-Step CSI Prediction

Code, results and paper for the ICASSP 2027 submission
*DD-Koopman: Compact Spectral Transfer for Multi-Step CSI Prediction*
(Jiaxin Liu, Nanjing University).

DD-Koopman is a 173,190-parameter CSI predictor that lifts the observed
history into the delay–Doppler plane and evolves it there with a diagonal,
observation-conditioned operator held fixed across horizons. On the official
CSI-4CAST TDD grid it reaches 0.1402 mean NMSE against the 21.9M-parameter
reference's 0.1246, with 126.5× fewer parameters and 4.98× lower latency,
and it holds a three-seed advantage on unseen propagation conditions.

## Verify every number in the paper

```
python code/analysis/audit_claims.py
```

One command checks all 492 presence claims (each printed number against its
source file under `results/`) and recomputes all 127 derived numbers (table
deltas, ratios, seed means, paired CIs) from the CSVs. Expected output:
`492/492 checks pass` and `127 derived-number checks, 0 failures`.

## Repository layout

| path | contents |
|---|---|
| `paper/` | LaTeX source of the submission and the compiled `main.pdf` |
| `code/models_ours/` | the reported architecture (`dd_koop.py`) |
| `code/models_baseline/` | re-implemented baseline architectures (Table 1) |
| `code/harness_patches/` | training / evaluation / profiling entry points |
| `code/config/sweep/` | training configuration of every run in `results/run_csv/` |
| `code/analysis/` | the audit gate and every derived-table regeneration script |
| `results/` | scored evidence: per-run tables (`run_csv/`), derived tables (`analysis/`), the benchmark's published reference rows (`reference/`) |

## Reproducing the derived tables and figures

Every derived table under `results/analysis/` is regenerated from
`results/run_csv/` by the scripts in `code/analysis/` (single entry point:
`python code/analysis/regenerate_all.py`; idempotent — a second run
reproduces every table byte-identically). Figure 2 is regenerated by
`paper/figures/make_fig_pareto.py`.

## Data

Training and evaluation use the CSI-4CAST benchmark (IEEE TMLCN 2026;
arXiv:2510.12996). Its published reference rows ship in
`results/reference/`; the benchmark harness and the datasets themselves come
from the project's Hugging Face organisation (`CSI-4CAST`) — see
`code/README.md` for the exact setup steps.

## Environment

Python 3.11; `pip install -r requirements.txt` (exact verified versions in
`requirements-lock.txt`). Training and evaluation ran on one RTX 3090 and one
RTX 5060 GPU; inference-latency profiling on an RTX 4090 D.
