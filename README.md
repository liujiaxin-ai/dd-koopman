# DD-Koopman: Exactness on a Budget for Compact Multi-Step CSI Prediction

Code, results and paper for the ICASSP 2027 submission
*DD-Koopman: Exactness on a Budget for Compact Multi-Step CSI Prediction*
(Jiaxin Liu, Nanjing University).

DD-Koopman is a 173,190-parameter CSI predictor that separates input-side
estimation from a compact observation-conditioned spectral transfer in the
delay–Doppler plane. On the official CSI-4CAST TDD grid it reaches 0.1402
mean NMSE against the 21.9M-parameter reference's 0.1246, with 126.5× fewer
parameters and 4.98× lower latency, and it holds a three-seed advantage on a
432-setting unseen-propagation slice.

## Verify every number in the paper

```
python code/analysis/audit_claims.py
```

One command checks all 580 presence claims (each printed number against its
source file under `results/`) and recomputes 131 derived numbers (table
deltas, ratios, seed means, paired CIs) from the raw CSVs. Expected output:
`580/580 checks pass` and `131 derived-number checks, 0 failures`.

## Reproducing the derived tables and figures

Every derived table under `results/analysis/` is regenerated from
`results/run_csv/` by the scripts in `code/analysis/` (single entry point:
`python code/analysis/regenerate_all.py`; idempotent). The Pareto figure
(Fig. 3) is regenerated by `paper/figures/make_fig_pareto.py`.

The exactness ladder (E0 periodic continuation, E1 ridge-fitted readout) is
reproduced end to end with `code/ladder/`; see `code/README.md` for the
install/fit/evaluate commands and the row-count gates.

## Data

Training and evaluation use the CSI-4CAST benchmark (IEEE TMLCN 2026;
arXiv:2510.12996). Its published reference rows ship in
`results/reference/`; the benchmark harness and the datasets themselves come
from the project's Hugging Face organisation (`CSI-4CAST`) — see
`code/README.md` for the exact setup steps.

## Environment

Python 3.11; `pip install -r requirements.txt` (exact verified versions in
`requirements-lock.txt`). Training and evaluation ran on one RTX 3090 and one
RTX 5060 GPU; inference-latency profiling on an RTX 4090 D.
