# DEPRECATED — do not quote the confidence intervals from this file

`generalization_by_cm.csv` was produced by an older code path
(`code/analysis/generalization_by_cm.py`). Its paired-bootstrap intervals differ
from the re-generated ones in the 4th decimal (e.g. `[-0.0585, -0.0333]` here
vs `[-0.0589, -0.0332]` there) because the bootstrap RNG is consumed in a
different order. The point estimates agree; the intervals do not, and a paper
must not carry two slightly different intervals for the same quantity.

## Authoritative sources instead

| quantity | use this file | produced by |
|---|---|---|
| three-seed shift slice, per-seed and per-cm intervals | `generalization_seeds.csv` | `code/analysis/generalization_seeds.py` |
| the same numbers plus sign test and Wilcoxon | `stats_hardening.csv` | `code/analysis/stats_hardening.py` |
| mobility-band three-seed numbers (fig_condition) | `generalization_by_band.csv` | `code/analysis/generalization_by_band.py` |
| capacity controls on the 432 slice | `generalization_432_summary.csv` | `code/analysis/generalization_432_summary.py` |

Rule for the whole project: **every number in the paper has exactly one source
file**, and that file is regenerated by a script in `code/analysis/`.
